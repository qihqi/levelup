# Game log audit — September 10, 2026

Reviewed the retained `logs/websocket-9140.jsonl` and `.jsonl.1` records from
2026-09-10 22:55 UTC through 2026-09-11 03:43 UTC. These are real server records
(0.5-second draws). Five other process log files contain automated tests with
100000-second draw intervals and intentionally invalid requests; they were excluded
from gameplay findings. No running server was restarted or room state changed.

## Confirmed bug: heartbeats reject valid player actions

Room TME52M has five `操作太快，请稍候。` errors immediately after automatic `ping`
requests. All five attempted plays had the correct turn and version, owned cards,
and valid suit/structure. The server updated the action rate-limit timestamp for
every incoming message before checking for `ping`, so background keepalives
consumed the player's 80 ms action allowance.

| Time (Pacific, September 10) | Round / trick | Gap after ping |
| --- | --- | --- |
| 18:34:35 | 2 / 1 | 38 ms |
| 18:35:00 | 2 / 3 | 33 ms |
| 18:59:10 | 7 / 5 | 11 ms |
| 20:06:02 | 12 / 18 | 60 ms |
| 20:08:57 | 13 / 7 | 79 ms |

Fixed `server.py` to process `ping` independently of player-action throttling.
The regression test verifies ping → action succeeds, action → ping returns pong,
and action → ping → another immediate action still rate-limits the second action.

## Running server still uses the old final trump window

The retained real-game final-deal states consistently advertise 3 seconds,
including TME52M round 18. The source now specifies 60 seconds and explicit
confirmation, but editing Python files does not reload the running process.
Restarting the terminal server is required to load those changes and the heartbeat
fix. Restarting clears in-memory rooms.

## Follow-suit rejections and game consistency

Revalidated all 19 card-count/suit/structure rejections using the exact logged
hand, selected cards, level, trump and lead. All reproduced the rejection. This
does not establish the user's intent or exactly what their browser displayed.

One revealing example is NEHL4Q round 4, trick 10, at 16:26:30 Pacific: level 6,
spades trump, lead ♣6, attempted follow ♣J. The player still held trump. ♣6 is a
level card, so the required effective suit is trump; ordinary clubs cannot follow
it while trump remains. Several other rejections follow the same pattern.

Reconstructed all four starting hands from the completed tricks of each complete
round and checked each follow against the remaining hand:

- 26 complete rounds: NEHL4Q rounds 1–8 and TME52M rounds 1–18.
- 456 tricks and 1,368 following plays checked.
- Each round accounts for 100 played cards plus 8 bottom cards, all distinct IDs.
- Recomputed trick winners and trick points agree with the logs.
- Summed attacker trick points plus the recorded bottom multiplier agree with final scores.
- No decreasing state versions within a connection, and no real-server `send_failed` records.

These checks found no inconsistency in the retained records. They do not cover
unlogged earlier rooms, browser-only failures, or independently prove every rule
implementation correct.

## Logging cleanup and verification

Automated tests previously wrote their deliberately invalid traffic to `logs/`.
Added a session test fixture that directs their WebSocket logs to pytest's temporary
directory, preserving existing diagnostic files and separating future test traffic.

Validation: 25 server, timer and WebSocket logging tests passed after the fix.
